# Task Quality Rules

## Product Focus

All tasks must advance the playable FORGE//SHIFT experience toward a complete vertical slice.

## Verification Requirements

- Must be verifiable through automated testing or manual playtesting 
- Should not just repeat previous work
- Must include clear acceptance criteria
- Should integrate with existing systems where applicable

## Implementation Standards

- Must be implemented using existing code patterns
- Should leverage current architecture
- Must not introduce breaking changes unless absolutely necessary
- Code should follow established conventions in the project
