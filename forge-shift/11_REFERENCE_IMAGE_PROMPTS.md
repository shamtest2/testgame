# 11 — REFERENCE IMAGE PROMPTS
## FORGE//SHIFT

Use these prompts with an image-capable AI to visualize the product before major visual development.

The images are **quality-direction references**, not claims that the final browser game will be pixel-identical.

---

## PROMPT A — FINAL GAMEPLAY TARGET

Create a single premium AAA-inspired gameplay screenshot concept for an ORIGINAL HTML5 browser game intended for CrazyGames.

The game is called FORGE//SHIFT (working title).

Show a player-controlled futuristic traversal machine/character inside a colossal, believable megastructure. The player is actively reconfiguring the architecture around them using advanced engineering technology. A bridge, platform, gate or moving structural module is visibly changing state, opening a new route.

The image must communicate actual gameplay immediately.

Visual style:
- futuristic realism with tasteful stylization
- premium modern architecture
- monumental scale
- glass, engineered metal, concrete, composite materials
- realistic material response
- strong environmental depth
- cinematic lighting
- restrained cool accent lighting
- subtle atmosphere
- no generic cyberpunk look
- no excessive neon
- no cheap mobile-game aesthetic

Camera:
dynamic third-person cinematic three-quarter camera
slightly elevated
player clearly visible
world scale visible
camera must show the current interaction and the route it creates

Composition:
foreground = player and immediate interaction
midground = active transformation and route
background = gigantic architectural environment and destination landmark

HUD:
minimal, professional, readable
objective
Shift charge
run progress
no oversized UI

Make it look like a real playable game screenshot, not movie concept art, and not a Unity/Three.js demo.

Do not copy Minecraft, Blox Fruits, Roblox, Fortnite, Portal, Control, or any other existing title.

16:9 landscape.

---

## PROMPT B — ARCHITECTURAL TRANSFORMATION MOMENT

Create an original premium 3D browser-game gameplay reference image.

Show a player approaching a massive architectural Shift Node. A futuristic structural system is actively reconfiguring: a large bridge rotates, nested platforms move into alignment, and a previously inaccessible path becomes reachable.

The environment should look physically engineered and believable.

The player must remain the visual anchor.

Aesthetic:
- premium futuristic architecture
- stylized realism
- black/silver/stone/ceramic/material variety
- restrained energy lighting
- cinematic volumetric atmosphere
- realistic scale
- no rainbow colors
- no excessive bloom
- no generic sci-fi corridor

The image should answer:
“What did the player just change, and why does it matter?”

Show cause and effect clearly.

16:9.

---

## PROMPT C — RISK/REWARD RUN

Create a polished, realistic 3D gameplay screenshot for an original futuristic HTML5 game.

Show the player at a branching architectural route:
- one safe route is clearly visible;
- one dangerous route crosses moving machinery or unstable structures;
- the dangerous route visibly contains a valuable reward;
- the destination is visible in the distance.

The player is deciding which route to take.

Use:
- cinematic dynamic camera;
- strong depth;
- believable architecture;
- detailed but controlled materials;
- clear gameplay readability;
- subtle UI.

The environment should feel authored and intentional.

No copied game mechanics or recognizable franchise design.

16:9.

---

## PROMPT D — HUB / PROGRESSION

Create a premium futuristic game Hub for an ORIGINAL HTML5 browser game.

The Hub is a compact, elegant engineering chamber inside the same megastructure.

Show:
- player's futuristic shell;
- tool/loadout stations;
- visible progression modules;
- cosmetic collection display;
- a doorway leading toward the next sector.

Architecture:
minimalist futuristic engineering design
large glass and metal surfaces
realistic materials
controlled accent lighting
cinematic but practical
high-end game presentation

The Hub must feel like part of the same game as the gameplay references, not a separate art style.

No fantasy castle.
No cyberpunk neon city.
No generic floating hologram overload.

16:9.

---

## CONSISTENCY PROMPT

When generating additional reference images, preserve exactly the same:
- architectural language;
- material families;
- lighting philosophy;
- accent-lighting discipline;
- camera language;
- UI language;
- scale relationship;
- player silhouette.

Do not redesign the world in every image.

The reference set should look like frames from one real game.
